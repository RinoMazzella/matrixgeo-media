# MatrixGeo Map World — media

Photos of **MatrixGeo Map World**, the real-time world map of the Meshtastic Italia community.
They are used by the MatrixGeo banner on <https://www.meshtasticitalia.it>.

| Folder | Size | Use |
|---|---|---|
| `foto/lg` | 1920 × 1080 WebP | full-screen viewer |
| `foto/md` | 960 × 540 WebP | cards |

Map data from public and official sources (including INGV, EMSC, USGS, NASA, Copernicus, CelesTrak) and from the community radio network.
